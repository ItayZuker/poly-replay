What it is: Your Polymarket proxy / profile wallet — the address that holds USDC and positions. Usually different from the signing wallet address tied to your private key.

Where to get it:

  • Polymarket.com — open your profile / settings; copy the wallet address shown there

—

What it is: The signing key for your wallet (EOA). The app derives the Signer address from it and uses it to place Polymarket orders. It is stored encrypted — never shown again after save.

Where to get it (any wallet that can export a private key):

  • MetaMask — Account details → Show private key
  • Rabby — Account / Address management → Export private key
  • Phantom / other EVM wallets — Settings → Export private key (if supported)
  • Dedicated bot wallet — generate a new key and fund only what you’re willing to risk

Any exportable EOA key works. Hardware wallets usually cannot export a key for server bots.

  • FOK — Fill-Or-Kill: full size or nothing (default).
  • GTD — Good-Til-Date: resting limit buys at the Price ¢ from Apply-window start (only when Duration is 0, left bar is UP/DOWN Price, and no Gap).

  • FOK — Fill-Or-Kill: full size or nothing; retries on later ticks if it does not fully fill.
  • GTD — Good-Til-Date: rests a limit sell at fill + Take Profit as soon as the buy fills (skipped when TP is 100).
